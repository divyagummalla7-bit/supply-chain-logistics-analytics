# Supply Chain & Logistics Analytics

An end-to-end supply chain analytics project using Python, SQL, Power BI, and machine learning to analyze sales, profitability, customer segments, shipping performance, delivery delays, and product demand.

## 📌 Project Overview

This project analyzes the DataCo Supply Chain dataset containing more than 180,000 order-item records.

The project follows a complete analytics workflow:

- Data exploration and cleaning using Python
- Exploratory Data Analysis (EDA)
- SQL-based business analysis using MySQL
- Advanced SQL analysis using window functions
- Power BI dashboard development
- Demand forecasting
- ABC product classification
- Late-delivery prediction
- Machine learning model evaluation
- Data quality validation
- Git/GitHub project version control
